# Readme

Cài đặt các extension sau trong Visual Studio Code:

- ESLint
- Prettier

File `.vscode/settings.json` sẽ tự động ghi đè cấu hình ESLint và Prettier cho Visual Studio Code

## ESLint

Sử dụng phiên bản ESLint 8.57.1 để tương thích với extension [Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)
